# VI Awwab | Pharmacy HTAR WPD 2026

Production-ready static repository for **VI Awwab**, the Virtual Intelligence Pharmacist for Pharmacy Department HTAR Klang, World Pharmacists Day 2026.

VI Awwab is not an AI pharmacist and not a medication chatbot. Medication-specific questions are redirected to a pharmacist. Medical conditions, symptoms, diagnosis, and treatment decisions are redirected to a doctor.

## Locked Project Direction

- Promote HTAR Pharmacy Department.
- Celebrate World Pharmacists Day 2026.
- Explain pharmacists' job scopes.
- Increase appreciation of pharmacists.
- Preserve HTAR Pharmacy legacy.
- Keep Mr Awwab visible at all times.
- Portrait: VI fills the screen, dialogue at the bottom.
- Landscape: VI on the left, dialogue on the right.
- First department: OPD.
- Music slot: `assets/audio/head-in-the-clouds.mp3`.

## Run Locally

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```

## Content

Department content lives in `data/departments.json`. Add more departments there without changing the locked UI.
